# Semantic Forge

Cursor **MCP** for Power BI: analyze a `.SemanticModel` + `.Report`, write a **Word optimization plan**, then apply changes only after you say **yes**.

- **Team guide (browser):** https://glofoxinc.github.io/semantic_forge/DOCUMENTATION.html  
- **Repo:** https://github.com/glofoxinc/semantic_forge

## Repo layout

| Path | Contents |
|------|----------|
| **`docs/`** | `SKILL.md`, `SLACK-ANNOUNCE.txt` |
| **`forge/`** | MCP server, Python code, config, scripts, tests |
| **`.github/`** | CI and Pages |

Share files at repo root: `DOCUMENTATION.html`, `share-image.svg`, this `README.md`.

## Setup (once, about 5 minutes)

Open this repo in Cursor and say **Setup Semantic Forge**. If it needs a report folder, model folder, or a login, it will ask once.

Daily use: **Analyse this report and semantic model. Write the full Word plan.**
